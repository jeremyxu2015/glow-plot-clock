本版特点

按一下按钮，机械臂就把当前时间写到荧光屏上，24 小时制，荧光持续数分钟后渐息。

01项目概览

和原版相比，这一版做的改动：WEMOS D1（ESP8266） 替代 Arduino Uno；WiFiManager 配网 + 阿里云 NTP 自动联网校时，因此不再需要 DS1307 RTC 模块和电池；时间精度由网络保证，永不漂移。

工作原理

  1. 按下按钮（或 D3 引脚接地），触发中断
  2. 两块 9g 舵机联动，把 UV LED 移动到目标坐标
  3. 从 NTP 读当前时间，按字形拆解为直线与圆弧
  4. UV 灯贴着荧光膜"扫"出 时:分，荧光通体发亮
  5. 写完机械臂回位、舵机断电，荧光约数分钟后渐息

04接线

这是本版与 Arduino 原版差异最大的地方。WEMOS D1 的引脚分配如下（固件里写死的，别接错）。

接线示意图

功能WEMOS D1 引脚GPIO连接说明
左舵机信号D6GPIO12舵机 VCC→5V、GND→GND
右舵机信号D7GPIO13同上
UV LED 正极D5GPIO14经 100Ω 电阻；LED 负极→GND；低电平点亮
按钮一脚D3GPIO0使用板载上拉，另一端接 GND；按下触发
舵机电源5V / GND—两舵机 VCC 并到 5V，GND 并到地；建议外接 5V 电源与 D1 共地
注意事项
  • 接线顺序建议：先接 GND 与电源，再接信号线，最后接按钮；每接完一排用万用表/目视检查一遍再上电。
  • D3 / D4 / D8 是启动敏感引脚，本版把按钮放在 D3（内部上拉 + 接地触发），不要给 D4/D8 挂负载。
  • 舵机供电强烈建议独立 5V 电源并与 D1 共地，否则写字瞬间电压跌落会导致 D1 重启。

05固件烧录与配网

固件在 PlotClock-ESP8266/PlotClock-ESP8266.ino。已内置配网与校时逻辑，烧完后几乎开箱即用。

1装 ESP8266 板卡包

Arduino IDE → 首选项 → 附加开发板管理器网址：

http://arduino.esp8266.com/stable/package_esp8266com_index.json

「开发板管理器」搜索 esp8266，安装 ESP8266 Community 的包。

2装库

库管理器搜索安装：WiFiManager by tzapu。

ESP8266WiFi、Servo、time.h 都随板卡包自带，无需额外安装。旧版的 Time / DS1307RTC 库本版不再需要。

3烧录

打开 PlotClock-ESP8266.ino，开发板选 LOLIN(WEMOS) D1 R2 & mini，选择端口（Mac 上通常是 /dev/cu.usbserial-xxxx）→ 上传。

4可调宏

代码顶部可开关：OPTION_12_HOUR（12 小时制）、CALIBRATE（校准）、GRID（点阵验证）。默认是 24 小时制 + 正常模式，开箱即可。

配网与校时（无需 RTC）

首次上电

  1. 上电后 D1 开启热点 PlotClock-Setup
  2. 手机连接该热点，会自动弹出配置页（若未弹出打开 192.168.4.1）
  3. 选择你的 WiFi 并输入密码保存，D1 自动连接
  4. 若 180 秒内未配网，会自动重启重新进入配网模式

自动校时

  1. 连上网络后自动以 ntp1.aliyun.com / ntp2.aliyun.com / pool.ntp.org 校时
  2. 时区固定为 UTC+8（北京时间），不用设置
  3. 之后每次画时间都先读网络时间，永远不会漂移
  4. 想重新配网：烧录时选「Erase Flash: All Flash Contents」擦除后重拍上电

06机械装配

机械部分与原版一致。核心顺序：先接线上电验证 → 再装机械臂 → 最后合壳，出问题好排查。

6.1 准备电子件
  • UV LED 两个脚焊上约 10cm 引线（正极是长脚），套热缩管防短路
  • 按钮两个脚也焊上引线
  • 两个舵机确认是正向 0–180° 舵机（舵盘四角都有螺丝孔），装入外壳前面板对应舵机位，线从前方开口穿出
  • WEMOS D1 用双面胶/热熔胶固定在外壳内部
6.2 接线（对照第 04 节）
  • 按接线表和接线图把所有连线接好，统一共地
  • 上电先用串口监视器（115200）观察：应打印 WiFi 连接信息与时间读数
  • 按一下按钮，如果舵机有动作就说明整链路通了（哪怕画得歪，后面校准）
6.3 组装机械臂
  • Arm1-2、Arm3、Arm4 之间用 M3 螺丝连接，转动顺畅不卡顿、无虚位
  • LED 装入臂端灯座，把 led_cover 聚光锥罩上去
  • 舵盘先套在舵机输出轴上（不拧紧），用手把机械臂转到大致中位附近再上紧舵盘螺丝
  • 把机械臂组件固定到舵机上（左右对应 D6 左 / D7 右，别装反了）
6.4 合拢外壳与表面处理
  • 前、顶、底壳用 M3 螺丝合拢；有走线需要时可用 Case_Top_Human 变体开孔
  • 荧光贴按前面板书写区剪裁，贴在 Case_Front 外侧，荧光面朝外
  • 四个橡胶脚垫贴到底部
  • 最后通电，进入第 07 节校准

07伺服校准

机械臂默认参数在各部件有公差时会画歪。校准分两步：CALIBRATE（对极限位置）→ GRID（验证点阵）。

常量默认值作用
SERVO_LEFT_ZERO1650左舵机零点（状态 1：左臂 0°）
SERVO_RIGHT_SCALE700右舵机转角→脉宽比例（状态 1）
SERVO_RIGHT_ZERO750右舵机零点（状态 2：右臂 0°）
SERVO_LEFT_SCALE650左舵机转角→脉宽比例（状态 2）
DRAW_DELAY3写字速度（ms/点），越大越慢越稳

ACALIBRATE 对角校准

  1. 取消 //#define CALIBRATE 注释，上传
  2. 机械臂每 2 秒在两个极限位置间切换，UV 灯交替亮/灭
  3. 亮的位置对应状态 2（SERVO_RIGHT_ZERO + SERVO_LEFT_SCALE）；灭的位置对应状态 1（SERVO_LEFT_ZERO + SERVO_RIGHT_SCALE）
  4. 调节这四个常量，让两个落点分别贴近荧光书写区的左下与右上极限，且覆盖面最大

BGRID 点阵验证

  1. 把 CALIBRATE 注释掉，取消 //#define GRID，上传
  2. 会在 0–70mm × 0–40mm 区域、每 10mm 打一个 UV 点（共 5×8 个点）
  3. 检查点阵是否横平竖直、对称居中，微调常量直到点阵方正

C恢复正常模式

  1. 两个宏都注释掉，重新上传
  2. 按按钮验证时间书写居中，荧光效果完整
  3. 校准参考视频（原版作者）：youtu.be/4viW9ADqX2w

08使用与常见问题

一切就绪后：按一下按钮，机械臂用 UV 灯把当前「时:分」写到荧光屏上，发光数分钟后渐息。可以反复按，每次都是崭新的时间。

舵机一直转 / 乱转？

用了连续旋转舵机。请换成正向 0–180° 舵机（舵盘四角都有螺丝孔）。

写出来的字歪斜、位置不对？

先做第 07 节的 CALIBRATE + GRID 两步校准，重点微调四个常量。

UV 灯不亮？

检查 D5 接线与 100Ω 电阻方向；LED 负极必须接 GND。注意它是低电平点亮，万用表量 D5 平时为高电平是正常的。

时间不对/不动？

确认已配网成功且网络可达（NTP 阿里云）。断网状态下时间会停留在最后成功校时的值。

字写得太快看不清 / 荧光太浅？

把 DRAW_DELAY 调大（如 5–8）放慢笔速；UV 灯落点贴近荧光贴面 5mm 内效果最佳；荧光贴选荧光绿。

想显示 12 小时制？

取消 //#define OPTION_12_HOUR 的注释后重新烧录。
